# pairwise-pngerr

## 题面（可直接粘贴）

让加载器对被截断的 PNG 返回可区分的错误，并保证失败路径无泄漏。约束：完整文件解析结果逐字节不变；三类截断给出不同错误码；失败后对象可复用；1 万次失败调用 RSS 不增长；并发加载同一数据安全；不改变对外 API。验收：python -m pytest tests -q -k png。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分，不在可见测试里）

- 三类截断错误可区分
- 失败后对象可复用
- 超大图流式
- 旧加载路径逐字节不变
- 失败路径不泄漏内存

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线），通过不代表满分。
